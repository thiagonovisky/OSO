Integrantes: Thiago Novisky, Jazmin Han, Tobias Balanofsky y Juan Spector
El proyecto se trata de buscarle una solucion a todos esos propietarios que estan cansados de usar excel. A traves de nuestra pagina podran tener toda la informacion de su propiedad en un solo lugar, de forma facil y ordenada
Para esto implementamos un registro e inicio de sesion, agregar propiedad, editar propiedad, menu de propiedades, calendario, mensajeria interna entre propietario e inquilino, analisis de contratos con IA, visualizacion de gastos y adjunto de comprobantes
Para ejecutar el proyecto tenes que tener abierto SQL con la base de datos y poner en la terminal la API de Gemini
