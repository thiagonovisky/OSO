- Integrantes: Thiago Novisky, Jazmín Han, Tobías Balanofsky y Juan Spector
- El proyecto se trata de buscarle una solución a todos esos propietarios que están cansados de usar excel. A través de nuestra página podrán tener toda la información de su propiedad en un solo lugar, de forma fácil y ordenada.
- Para esto implementamos un registro e inicio de sesión, agregar propiedad, editar propiedad, menú de propiedades, calendario, mensajería interna entre propietario e inquilino, análisis de contratos con IA, visualización de gastos y adjunto de comprobantes.
- Para ejecutar el proyecto tenés que tener abierto SQL con la base de datos y poner en la terminal la API de Gemini.
